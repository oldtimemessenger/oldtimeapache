# Oldtime workspace source

Public source snapshot for `oldtimemessenger/oldtimeapache`, prepared for design work across the active workspace.

## Included

All active tracked source, configuration, documentation, scripts, and required assets across the workspace artifacts, shared libraries, and services. This includes the current PWA, previous-address web artifact, API server, Expo wrapper, and component-preview sandbox.

## Excluded

Private agent notes, archived/deferred code, uploaded reference images and screenshots, credentials, environment files, production/user data, generated builds, dependency installs, caches, local runtime state, and the workspace Git history. Removed/deferred features are not restored by this export.

## Production safety

This repository is a source snapshot only. It does not enable automatic production deployment. Cloudflare secrets and production data remain outside GitHub; deployment and store releases remain separate actions.
