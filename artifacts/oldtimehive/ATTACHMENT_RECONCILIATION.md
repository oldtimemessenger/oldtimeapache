## Picker screenshot interpretation

The newest picker reference visibly has an app screenshot selected in the library. That is valid user media and should not be blocked just because it depicts the app. The requirement is to bind the preview to the selected file, never capture the live application as an automatic substitute. A selected screenshot and an accidental live-app capture are different cases.
